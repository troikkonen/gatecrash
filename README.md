# Gatecrash: Hold the Lane

Netlify-ready. Drop the folder on a site or push it to a repo Netlify watches. Open `index.html` over http(s) — the models load from `models/`, so it will not run from a `file://` URL.

Step 1 build: world, camera, rigged squad, drag control, auto-fire, enemy waves.

Models: `Soldier.glb` / `Xbot.glb` (Mixamo, via three.js examples), `RobotExpressive.glb` (Tomás Laulhé, CC0). three.js: MIT, from CDN.
